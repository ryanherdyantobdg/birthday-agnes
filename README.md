# 💗 Undangan Date — GitHub Pages

Website undangan date interaktif, gratis, tanpa backend.

## Cara pakai

1. Buat repository baru di GitHub, misalnya `undangan-date`.
2. Upload `index.html`, `style.css`, dan `script.js` ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu beberapa menit sampai website aktif.

## Membuat nama otomatis

Tambahkan `?name=Nama` di belakang URL.

Contoh:
`https://USERNAME.github.io/undangan-date/?name=Nadia`

Maka tulisan "Hey, Kamu" otomatis berubah menjadi "Hey, Nadia".

## Yang sudah tersedia

- Tombol NO yang kabur saat didekati
- Animasi transisi antar halaman
- Confetti setelah YES
- Tanggal fixed: Sabtu, 29 Agustus 2026
- Pilihan fixed: Dinner
- Waktu fixed: 20:00 WIB
- Halaman konfirmasi
- Halaman final "It's A Date!"
- Responsive untuk HP
- Tidak membutuhkan database, hosting berbayar, atau API

## Catatan

Font menggunakan Google Fonts. Kalau ingin benar-benar tanpa koneksi eksternal, hapus baris Google Fonts dari `index.html` dan gunakan font sistem.
